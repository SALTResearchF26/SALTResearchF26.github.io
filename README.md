# ABC Tutoring Website Prototype

Tutoring website prototype designed for Dana using HTML, CSS, Javascript, and PostHog Telemetry.

## Features

- Home page to display business goals and services
- Tutoring page to display available tutors and information: name, picture, subjects, grade, hourly rate.
- Booking form to book one-hour long sessions with available tutor. Provide time, parent information, and student information to book.

## PostHog Telemetry

The website tracks:

- Booking started
- Booking completed

## Running the Project

1) Clone the Repository
git clone https://github.com/SALTResearchF26/SALTResearchF26.github.io.git

2) Open the Project in VS Code
cd SALTResearchF26.github.io 
code .

3) Install Live Server
Open Extensions -> Search for Live Server -> Install the Live Server extension

4) Run the Website Locally
Open home.html in VS Code.

Right-click anywhere in the file and select:

Open with Live Server

The website should open in your browser at an address similar to:

http://127.0.0.1:5500/
